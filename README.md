# Educa+

Site de reforço escolar voluntário: jovens se cadastram para **dar** ou **receber** aulas de reforço na própria comunidade.

- **ODS atendido:** ODS 4 – Educação de Qualidade
- **Público-alvo:** estudantes do ensino fundamental e médio e jovens voluntários
- **Publicação:** https://SEU-USUARIO.github.io/educa-mais/

## Estrutura
